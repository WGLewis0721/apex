# Apex product film

The 20-second silent homepage film follows the product workflow in `STORYBOARD.md`. UI is reconstructed from current product components with authored fictional fixtures, never generated by the video model. The final outcome holds in the homepage player until a visitor explicitly replays it. The final WebP is also the reduced-motion and failed-media fallback.

## Render

Requires Python 3, Pillow, and FFmpeg. Download the reveal shot from `generation.json` into a local `reveal.mp4`, then from the repository root:

```sh
python scripts/film/render.py apex --reveal reveal.mp4 --out film-output --fonts scripts/film/fonts
```

Coordinates and font sizes are rasterized directly at 3840×2160, 30 fps. Output is a 4K H.264 master, a 1440×810 H.264 web encode, and an end-frame WebP. The compact H.264 master replaces the original proposed ProRes delivery to keep the archived originals manageable. Exact UI, code, sample names, arithmetic, and copy stay in the deterministic renderer. The generated shot is a brief tactile materials transition before the final UI, not a product capability claim.

Publish only `apex-product-film-v2.mp4` and `apex-product-film-v2.webp` to `public/assets/waitlist/`. The original decorative loop is retained for history but no longer referenced by the section.

## Fixture boundaries

All company, investor, transaction, code, class-material, and planning records are illustrative. No real customer data is used. Mobile/App Store availability, capital outcomes, learning results, and global code originality are not promised. The form and existing storage endpoint are unchanged.

## Playback acceptance

- Start when at least half the video is visible, and pause outside the viewport or when the tab is hidden.
- Hold the final frame; scrolling away and back never restarts a completed film.
- Keep a manual pause across scroll changes. Replay resets to zero.
- Reduced motion shows the final still, with explicit play available.
- Provide an expand control and a retry action if loading fails.
- Preserve name/email validation, consent, and success only after a confirmed API response.
