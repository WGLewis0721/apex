# APEX launch, distribution, and first-customer visuals

These graphics are meant to explain how APEX is bought, delivered, installed, and monetized without requiring the reader to understand infrastructure jargon.

## 1. Customer purchase funnel

![APEX customer funnel](../public/assets/launch/apex-customer-funnel.svg)

**Story:** discover APEX → choose a plan → pay → create a workspace → connect/install → go live.

## 2. How APEX ships

![How APEX ships](../public/assets/launch/apex-how-it-ships.svg)

**Story:** the customer installs a lightweight SDK/components in their app; APEX itself runs as hosted cloud infrastructure and stays synchronized with the payment provider.

## 3. Payment to product access

![Payment to access](../public/assets/launch/apex-payment-to-access.svg)

**Story:** Stripe answers whether money moved. APEX turns that event into credits, plan rights, usage state, and allow/warn/block behavior inside the product.

## 4. First-five-customer revenue loop

![First five customers](../public/assets/launch/apex-first-five-customers.svg)

**Story:** initially sell a guided founding-partner implementation, get customers live, observe repeated implementation work, and systematically productize it.

### Brand usage

- Green: connection / success / system state
- Blue: payment / API / infrastructure
- Rusty red: usage / credits / entitlements / limits
- APEX mark: green → blue → rusty-red gradient

The price points shown are launch-strategy examples and should remain easy to change from one central configuration if they are surfaced in the application.
